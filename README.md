# macOS iPhone Keyboard Sounds
This project brings iPhone typing sounds to macOS. 

## Setup
Because Apple's system sounds are proprietary, this repository does not include the audio files. You must have Xcode or the iOS Simulator installed to use this.

1. Install dependencies: \`pip install -r requirements.txt\`
2. Extract the sounds locally: \`python3 prepare_sounds.py\`
3. Run the keyboard listener: \`python3 keyboard_sounds.py\`
